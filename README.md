# Birosca 010

> O comércio da BR-010 na palma da mão.

Marketplace local para Dom Eliseu/PA e região. Conecta vendedores autônomos,
biroscas, produtores rurais e prestadores de serviço a compradores da região.

## 🎯 Sobre

Birosca 010 é a versão digital do comércio de bairro. Não é um marketplace
genérico — é uma plataforma pensada para a realidade local:

- Vendedores sem CNPJ (MEI, autônomos)
- Produtores rurais da região
- Prestadores de serviço (eletricista, encanador, diarista)
- Comércio tradicional da BR-010

## 🚀 Como Rodar

    # Servidor local
    python3 -m http.server 8000

    # Abrir http://localhost:8000
